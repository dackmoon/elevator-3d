# 3D 沉浸式可操作电梯（Elevator 3D）— 项目概要

## 1. 项目定位

打造一款在浏览器中即开即玩的 **第一人称沉浸式 3D 电梯模拟互动小游戏**（灵感源自经典 Flash 交互小游戏的轻巧趣味与强反馈感）。

玩家置身于一部细节丰富的 3D 电梯轿厢内，可以通过鼠标自由环顾四周、真实点击物理按钮面板、聆听机械音效并感受电梯启停的微弱惯性，探索打开电梯门后不同楼层的独特氛围与小彩蛋。

---

## 2. 技术方案与选型

前期坚持 **“纯代码程序化构建、零外部建模依赖”** 原则，快速跑通核心交互与沉浸感；后续支持无缝引入 Blender 导出的 `.glb` 模型进行美术升级。

| 模块 | 选型 | 说明 |
| --- | --- | --- |
| 3D 渲染引擎 | **Three.js** | 轻量、生态成熟、浏览器原生 WebGL 运行，体积小、加载快 |
| 构建工具 | **Vite + TypeScript** | 开发热更新极快，强类型有利于维护状态机与 3D 场景结构 |
| 材质与贴图 | **PBR 材质 + Canvas 动态纹理** | 程序化生成拉丝不锈钢、木纹/石材、按钮文字以及实时刷新的 LED 楼层点阵屏 |
| 动画控制 | **有限状态机（FSM）+ 缓动插值** | 精确控制开关门、加减速运行、按钮按压回弹与摄像机惯性晃动 |
| 音效系统 | **Web Audio API（实时合成）** | 无需外部音频素材即可合成按键声、电机低鸣、开关门滑轨声、到站“叮咚”与警铃声 |

## 3. 核心功能规划

### 3.1 沉浸式 3D 轿厢场景
- **轿厢结构**：拉丝金属/木饰面墙板、防滑地板、嵌入式顶部照明灯带、金属扶手、背墙反射效果、左右双开滑动电梯门。
- **主控按钮面板（COP）**：
  - 楼层数字按键（支持悬停微高亮、点击物理下陷回弹、背光环形点亮）。
  - 功能按键：`开门 (◄►)`、`关门 (►◄)`、`警铃 (🔔)`、`照明/应急灯开关`、`风扇开关`。
- **动态指示系统**：
  - 门头上方 + 按钮面板顶部的 **LED 点阵显示屏**，实时显示当前楼层数字、上下运行箭头（`▲` / `▼`）及状态提示（如超载/紧急状态）。

### 3.2 真实物理交互与操控手感
- **视角控制**：第一人称站在轿厢内，支持平滑鼠标拖拽环顾（或准星聚焦操作），并可一键快捷聚焦到按钮面板 / 电梯门视角。
- **电梯调度状态机**：
  - 状态流转：`IDLE（待机）` → `CLOSING（关门）` → `MOVING（运行中）` → `OPENING（开门）` → `OPEN（停留等待）`。
  - 支持多楼层连续点选、同方向顺路停靠、关门中按开门键立即重新弹开、双击取消已选楼层。
- **运动体感反馈**：
  - 升降过程采用 **Ease-In-Out（缓启缓停）** 速度曲线。
  - 启动加速与到站刹停瞬间触发轻微的摄像机垂直惯性位移，运行途中伴随极其细微的机械震动，强化真实乘梯体感。

### 3.3 多楼层“门外世界”与趣味彩蛋
每到达一个楼层，电梯门打开后可透过门框看到风格迥异的走廊/外部景观（初步规划 5~8 层，可随时扩展）：
- **`B2` 地下车库**：冷色调微暗灯光、水泥柱、隐约闪烁的日光灯管。
- **`B1` 设备/后勤层**：暖黄工业灯光、管道与警示条纹。
- **`1F` 现代大堂**：明亮通透的大理石空间与柔和暖光。
- **`3F` 办公区**：温馨木质格调与指示门牌。
- **`5F` 室内花园 / 艺术走廊**：彩色氛围光与极简几何雕塑。
- **`8F` 顶层星空观景台**：深邃夜空、闪烁星光与远景城市剪影。

*(若启用观光玻璃背墙，升降过程中窗外楼层结构与远景会实时随高度上下掠过。)*

### 3.4 沉浸式拟真音效
- 按键按下：清脆机械微动开关“咔哒”声。
- 关门/开门：低沉顺滑的门轨滑动与合拢轻碰声。
- 运行中：随速度变化音调的曳引机电机运转嗡鸣。
- 到站提示：经典双音阶“叮—咚”钟声。
- 彩蛋机关：警铃急促蜂鸣、照明切换继电器“啪嗒”声、通风扇微弱风噪。

## 4. 拟定目录结构

```text
elevator-3d/
├── docs/
│   └── PROJECT_OVERVIEW.md   # 项目概要与设计文档
├── public/                   # 静态资源（后续可放外部贴图或 .glb 模型）
├── src/
│   ├── main.ts               # 应用入口与渲染循环
│   ├── scene/
│   │   ├── ElevatorCabin.ts  # 轿厢几何结构、灯光、材质与双开门
│   │   ├── ControlPanel.ts   # 物理按钮面板生成、按压动画与发光状态
│   │   ├── FloorDisplay.ts   # Canvas 动态 LED 楼层显示屏
│   │   └── FloorWorlds.ts    # 各楼层门外场景与环境氛围切换
│   ├── core/
│   │   ├── ElevatorFSM.ts    # 电梯调度逻辑与状态机
│   │   ├── CameraRig.ts      # 第一人称视角控制与启停惯性体感
│   │   └── Interaction.ts    # 射线检测（Hover / Click / 长按）
│   ├── audio/
│   │   └── SoundEngine.ts    # Web Audio API 实时音效合成器
│   └── ui/
│       └── HudOverlay.ts     # 极简辅助提示（视角切换/快捷键/静音）
├── index.html
├── package.json
└── tsconfig.json
```

## 5. 分阶段开发计划

### Phase 1：最小可玩原型（MVP）
- [x] 初始化 Vite + TypeScript + Three.js 工程。
- [x] 搭建基础 3D 轿厢（墙面、地板、顶灯、左右滑动门）。
- [x] 实现基础控制面板（若干楼层键 + 开关门键）与射线点击交互。
- [x] 跑通电梯状态机（选层 → 关门 → 模拟运行 → 开门）与动态 LED 楼层屏。

### Phase 2：沉浸感与操控打磨
- [x] 细化材质质感（拉丝金属、反光、氛围灯光、扶手与细节装饰）。
- [x] 加入按钮物理按压回弹动画、悬停高亮提示与第一人称视角平滑控制。
- [x] 加入启停镜头惯性顿挫与运行微震效果。
- [x] 接入 Web Audio API 合成全套电梯拟真音效。

### Phase 3：门外世界与趣味彩蛋
- [x] 为不同楼层构建风格鲜明的门外场景与灯光氛围（`B2 ~ 6F` 共 8 层）。
- [x] 增加趣味互动机关：警铃（红灯闪烁 + 铃声）、灯光/应急模式切换、风扇开关、双击取消楼层。
- [x] 加入观光玻璃井道与窗外夜景/星空，运行中可见钢架与发光楼层牌高速掠过。

### Phase 4：进阶扩展（可选）
- [ ] 支持加载外部 Blender（`.glb`）精细道具或复古电梯皮肤切换。
- [ ] 移动端触控适配与性能优化。
