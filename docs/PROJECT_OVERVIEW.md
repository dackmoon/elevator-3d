# 3D 沉浸式可操作电梯（Elevator 3D）— 项目概要与架构设计

## 1. 项目定位

打造一款在浏览器中即开即玩、兼容桌面端与 iPad 触控的 **第一人称沉浸式 3D 电梯模拟互动作品**（致敬经典 Flash 交互小游戏的即时反馈与探索乐趣）。

玩家置身于一部 20 层高层观光电梯轿厢内，通过自然的拖拽手势环顾四周、真实按压物理按钮面板、聆听机械声效与中文真人报站，并在启停惯性中探索每一层开门后的独特照片级世界与雨夜都市高空景观。

---

## 2. 技术栈与渲染管线

项目采用 **“程序化 3D 轿厢 + AI 照片级门外实景 + 全程序音频与 TTS 播报”** 混合架构，无需 Blender 建模即可达到高写实度，且前端零重型框架依赖。

| 模块 | 选型 | 职责与实现亮点 |
| --- | --- | --- |
| 3D 引擎 | **Three.js (`^0.174`)** | WebGL 渲染、PBR 材质、射线检测与自定义 GLSL Shader |
| 后期与环境光 | **`RoomEnvironment` + `EffectComposer` + `UnrealBloomPass`** | 物理级环境反射（`environmentIntensity = 0.16` 柔和不刺眼）+ 高阈值电影辉光（`threshold = 0.96`，仅自发光灯源泛光）+ `ACESFilmicToneMapping` |
| 构建与语言 | **Vite 6 + TypeScript 5（Strict）** | 极速热更新、强类型约束、静态产物可直接托管至任意 Web 服务器 |
| 材质与动态屏 | **Canvas 2D 程序化纹理 + GLSL** | 喷砂微拉丝金属、温润胡桃木、大理石拼花、20 层双列楼层指南、实时刷新的 LED 点阵屏与后窗动态雨滴着色器 |
| 门外实景 | **硅基流动 `Qwen/Qwen-Image` + 曲面巨幕投影** | 20 层 `1664×928` 高清摄影实景，等比贴合 126° 曲面巨幕并配 3D 过渡地板与降级程序化 3D 备选场景 |
| 音效与语音 | **Web Audio API + `CosyVoice2-0.5B`** | 零素材实时合成按键/滑门/电机/叮咚/警铃/风扇/雨声 + 24 条温柔女声 MP3 播报，经吸顶喇叭 EQ 统一输出 |

## 3. 空间坐标系与防穿帮设计

为了让灯光阴影、摄像机焦点和按钮射线检测始终保持最高浮点精度，**轿厢固定在世界原点，外部井道与楼层世界沿 `-Y` 随 `elevator.elevation` 反向移动**（远景都市群带 `0.28×` 垂直视差）。

- **轿厢尺寸（1 unit = 1m）**：
  - 宽 `2.10m`（`X ∈ [-1.05, +1.05]`）、高 `2.55m`（`Y ∈ [0, 2.55]`）、深 `2.00m`（`Z ∈ [-1.00, +1.00]`）。
  - 前墙双开联动门（内轿门 `Z = -1.03` + 外厅门 `Z = -1.095`），门套立体前凸（`Z = -0.938`）与前墙、门楣严格零共面重叠，彻底避免 Z-fighting 闪烁。
  - 右侧前墙挂载 `0.40m × 1.28m` 宽体 4×5 物理按钮面板；左墙挂载 20 层双列楼层索引铭牌；后墙为全景观光玻璃窗与防撞不锈钢护栏。
- **门外实景单层隔离与过渡地板**：
  - `FloorWorlds` 每帧仅渲染距离当前高度最近的 **1 个门外候梯厅**（提前 `1.6` 层异步预加载实景图），从物理上杜绝上下楼层串台或同半径曲面重叠加闪。
  - 每个实景层脚下铺设与楼层主题一致的 3D 半圆过渡地板（`Y = -0.012`）与顶部收口遮罩，平视 100% 展示等比高清建筑实景，低头看门槛脚下自然衔接不露空。

## 5. 核心系统设计

### 5.1 电梯有限状态机（`src/core/ElevatorFSM.ts`）
- 状态流转：`IDLE` ↔ `CLOSING` → `MOVING` → `OPENING` → `OPEN`。
- **LOOK 顺路调度**：优先响应当前运行方向上的最近楼层，支持途中新增顺路停靠、关门中按开门键即时弹开、双击取消已选楼层并自动安全就近停靠。
- **高速运动学**：最高速度 `6.2 m/s`、加速度 `2.6 m/s²`，输出实时 `elevation / velocity / acceleration` 同步驱动外部世界移动、电机音频变频与摄像机弹簧阻尼惯性体感。

### 5.2 桌面 + iPad 统一交互系统（`src/core/CameraRig.ts`、`src/core/Interaction.ts`）
- **自然拖拽方向**：向右/向下拖动画布，画面跟随手指平滑移动（与全景看房/iPad 触控习惯一致），采用沉稳阻尼与适中灵敏度。
- **多点触控支持**：单指拖拽环顾、双指捏合缩放 FOV、双指切换不跳屏；触控端轻点防抖阈值 `12px`，避免手指按按钮误判为拖拽。
- **快捷视角预设**：支持一键平滑过渡至 `默认视角`、`特写面板`、`楼层指南`、`观光后窗`。

### 5.3 音效与中文播报引擎（`src/audio/SoundEngine.ts`）
- 首次点击/轻触自动解锁 `AudioContext`（兼容 iPadOS Safari）。
- 全套机械音效纯 Web Audio 节点实时合成（零外部音效依赖）；24 条中文语音 MP3 经 `decodeAudioData` 缓存并通过吸顶喇叭带通 EQ 播放，内置防重叠队列与静音总控。
